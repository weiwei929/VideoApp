关于 VideoApp

什么是 VideoApp?

VideoApp 是一个个人视频管理和播放系统，为用户提供本地视频管理和 PikPak 云盘集成。该应用程序使您能够在一个地方组织、管理和观看您的所有视频内容。

主要功能
  • 本地视频管理与播放
  • PikPak 云盘视频集成
  • 高质量视频播放器
  • 视频分类与搜索
  • 简洁现代的用户界面
技术栈

VideoApp 使用以下技术构建：

  • Django (Python Web 框架)
  • Django REST Framework
  • Bootstrap 5
  • VideoJS (视频播放器)
  • PikPak API
  • SQLite 数据库
